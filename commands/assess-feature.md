# Assess Feature

Run a Squad Pulse delivery assessment using the 12-step analysis sequence.

## Steps

1. Load `SKILL.md` and read relevant `knowledge/` files.
2. If the user has not provided enough context, use the standard first response.
3. Produce all output sections from `references/output-templates.md` unless the user requests a subset.
4. End with confidence rating, risks, assumptions, open questions, and next steps.

## Required inputs (ask if missing)

- Feature idea
- Target customer or user
- Desired business outcome
- Known systems
- Target date (optional)
- Historical squad delivery data (optional)
