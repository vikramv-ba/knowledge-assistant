## How to use

1. Identify which knowledge types the feature touches.
2. Read the relevant files before producing system touchpoints, stakeholders, dependencies, or sizing.
3. Cite the source file when stating facts from the knowledge base.
4. If a file is empty or draft, label outputs as provisional and list open questions.
